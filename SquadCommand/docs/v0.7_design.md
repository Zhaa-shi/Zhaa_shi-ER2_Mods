# ER2 SquadCommand v0.7 交互设计

## 参考 RTS 游戏操作逻辑

参考《地狱之门：东部前线》(Gates of Hell: Ostfront)、《战争之人》(Men of War)、《英雄连》(Company of Heroes) 的经典 RTS 操作：

### 选择模型
| 操作 | 行为 |
|------|------|
| 左键单击友军单位 | 选中（替换选择）：步兵=单兵，载具=整车组 |
| 左键拖动框选 | 框内全部友军选中（替换选择） |
| Shift+左键 | 追加到当前选择 |
| 左键空白 | 清空选择 |
| 双击友军 | 选中该单位所在小队全部成员 |

### 框选组建新小队（核心特性）
- 框选后，框内**步兵从各自原小队**抽离，`Leave()` 后 `Join()` 到一个**新创建的小队**（`new Squad(guid, true)`）
- **载具车组**不拆散：整车组作为 1 个单位纳入选择组，不改变其车组小队
- **火力点**（MG 巢/反坦克炮）等同载具处理
- 原小队若空 → `RemoveNullUnits()` / `ClearEmptySquads()` 自动清理 = 不拖欠不残留

### 指令（右键）
| 操作 | 选中单位的行为 |
|------|---------------|
| 右键地面 | 移动（仅选中的单位） |
| 右键敌军 | 攻击（forceTarget） |
| 右键友军载具(未选中) | 上车（squad.boardVehicle 或逐员 boardVehicle） |
| 右键已选中载具 | 载具开过去（不下车，driveTo） |
| 空格 | 暂停/继续世界 |
| 下车按钮 | 已选载具车组全部下车（ForceExitAllVehicle） |

### 编队状态
- 当前选择 = 1 个步兵小队（mainSquad）+ 0~N 个载具车组小队（selVehicles）
- 移动时：步兵逐单位 moveTo（不碰未选），载具车组 Lua_Squad.moveTo 开过去
- 标记：选中单位身上 ◆ 光标

### 根治光标闪烁
- Harmony patch `Cursor.set_lockState`：上帝视角时强制 `None`，原生代码永远锁不了
- Harmony patch `Cursor.set_visible`：上帝视角时强制 `true`
- 同步保留现有 AssertFreeCursor + FrameEndGuard 兜底

### 界面
- 取消右下角小队分类面板
- 底部居中操作提示：WASD 滚轮 中键 左键 右键 空格
- 左上角暂停指示 + 选择数量
- 顶部控制按钮 + 下车按钮
- 选中单位 ◆ 标记
