# ER2 Squad Command — RTS 上帝视角小队指挥

## Description
为 Easy Red 2 增加一套「RTS 上帝视角」小队指挥系统，鼠标操作逻辑参照《地狱之门：东部前线》。按 F9 进入自由上帝视角俯瞰战场，**长按左键框选即可组建真实的新小队**：框内步兵会从各自原小队抽离，编入一个新建小队（游戏内真实编队，非临时选择）；载具车组不拆散，整体作为 1 个单位纳入选择。右键下指令（移动/攻击/上车/下车），空格暂停世界从容指挥。接管时随机进入一名存活选中成员继续战斗。

## Installation instructions
1. 安装 BepInEx（IL2CPP 版）到游戏根目录。
2. 将 `ER2_SquadCommand.dll` 放入 `Easy Red 2\BepInEx\plugins\`。
3. 启动游戏，BepInEx 日志出现 `Loading [ER2 Squad Command 0.7.3]` 表示加载成功。

## Main features
- **上帝视角指挥**：F9 进入自由视角，WASD 移动、滚轮缩放、中键旋转、Q/E 升降，空格暂停/继续世界。
- **框选组建真实新小队**：长按左键框选 → 框内步兵从原小队抽离并编入**新建的真实小队**；原小队变空自动清理，不拖欠不残留；Shift+框选 = 追加。
- **地狱之门式鼠标交互**：
  - 左键点击友军士兵/载具 = 选中（载具整车组算 1 个单位），左键点击敌军 = 攻击，左键空白 = 清空
  - 双击友军 = 选中该单位整个小队
  - 右键 = 下指令（地面=移动、敌军=攻击、友军载具未选中=上车、友军载具已选中=让载具开过去）
  - 只有身上带 ◆ 光标（被选中）的单位响应移动，未选单位不动
- **载具与火力点**：点载具/火力点直接选中整车组（不用点里面的乘员）；**小队级上车**（右键友军载具/点火力点内士兵）；顶部 [下车] 按钮让已选载具车组全部下车。
- **随机接管**：选中单位后点顶部 `[控制该小队]`，随机接管一名存活成员回到第一人称；全军覆没时可 F9 紧急退出。
- **根治光标闪烁**：上帝视角下 patch `Cursor.set_lockState`，原生无法锁/隐藏光标——右键不再闪烁或重置到屏幕中央。
- **压制原生干扰**：进入时解除本阵营小队的原生任务拉取；接管时自动关闭原生"选择队友"残留面板。

## Requirements
- Easy Red 2
- BepInEx（IL2CPP 版）
