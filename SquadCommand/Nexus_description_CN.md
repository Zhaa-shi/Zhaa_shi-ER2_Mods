# ER2 Battlefield Commander — RTS 上帝视角小队指挥

## Description
为 Easy Red 2 增加一套「RTS 上帝视角」小队指挥系统，鼠标操作逻辑参照《地狱之门：东部前线》。按 F9 进入自由上帝视角俯瞰战场，长按左键框选友军进行临时选择，不会自动拆散原生小队；只有显式点击 [分队] 才会创建真实新小队。载具车组不拆散，整体作为 1 个单位纳入选择。右键下达移动、集火标记、上车、下车和车辆移动指令；右键长按拖动拉出阵型箭头：步兵沿阵型线排开或走原生掩体系统进掩体（拖动时有白色半透明预览），载具占线槽开到位后按箭头方向转向。下达命令后单位到目标间显示灰色细虚线路线，到位自动消失。空格暂停世界从容指挥。已经下达的移动、集火、登车和车辆同步任务会在切回 FPS 后继续执行；FPS 原生移动、视角和射击不受影响。接管时随机进入一名存活选中成员继续战斗。

## Installation instructions
1. 安装 BepInEx（IL2CPP 版）到游戏根目录。
2. 将 `ER2_BattlefieldCommander.dll` 放入 `Easy Red 2\BepInEx\plugins\`。
3. 启动游戏，BepInEx 日志出现 `Loading [ER2 Battlefield Commander 1.4.23]` 表示加载成功。

## Main features
- **上帝视角指挥**：F9 进入自由视角，WASD 移动、滚轮缩放、中键旋转、Q/E 升降，空格暂停/继续世界。
- **临时框选与显式分队**：长按左键框选只改变当前选择，不自动拆队；点击顶部 [分队] 时才创建真实新小队；Shift+框选 = 追加。
- **地狱之门式鼠标交互**：
  - 左键点击友军士兵/载具 = 选中（载具整车组算 1 个单位），左键点击敌军/空白 = 清空选择
  - 双击友军 = 选中该单位整个小队
  - 右键短按 = 下指令（地面=移动、敌军=持久标记集火、友军/中立载具或火力点=直接上车/进入、车内友军=补员上车、建筑/房屋=选中步兵进入找掩体防守），右键双击 = 原生「前往并防守」
  - **右键长按拖动 = 阵型箭头（地狱之门式）**：阵型线中心=长按点、垂直于箭头、长度=箭头长度，单位面向箭头方向。目标区附近有原生掩体点（沙袋/墙沿/Combat Cover 道具等）时，步兵逐一分配掩体、走原生掩体系统进掩体（自动按掩体建议姿态/朝向驻守）；其余沿阵型线排开。拖动中有白色半透明幽灵模型预览掩体位，另有阵型线/排开/载具槽标记。载具占线槽开到位后按箭头方向原地转向
  - **命令快捷键**（可改键）：Z 站起 / X 蹲下 / C 趴下 / V 停止 / B 停火切换 / N 就近掩体 / M 集合 / F 分散
  - **行进路线显示**：下达移动或登车命令后，每个行进单位到目标画灰色半透明虚线（登车线实时跟随载具），到位后消失
  - Ctrl+1~9 保存当前选择为编组，1~9 一键召回（死亡单位自动剔除）
  - 只有身上带 ◆ 光标（被选中）的单位响应移动，未选单位不动
- **左下角信息面板**：焦点单位的姓名/职类、血量条、姿态、压制度；◀ ▶ 在选中单位间循环。选中载具时另有 [下车] / [修理] 按钮（右键交互环已删除）。不可移动的火力点/火炮只接受阵型转向——箭头让它们原地转向。左键可点选尸体（不分阵营）。
- **格子背包窗口（1.3.2）**：[背包] / [货舱]（或 G 键）打开 MC 风格格子窗口——游戏原生物品图标、数量角标、悬停提示、负重条，每页 6×4 格可翻页。同类物品合并成一格（×N = 总数）并按分类排序。可同时开多个窗口，整组拖拽在窗口间移动/交换（全部带负重校验）；拖到窗口外松手即扔在地上——穿戴/手持的武器也能拿起扔掉（走原生卸下路径）。**右键尸体打开其背包（1.4.11 起同时打开选中单位的背包）；右键徒步友军打开双方背包——两种情况都是最近的选中士兵先走到联动半径内（到达后窗口自动打开；1.4.9 起兵一停下来就再触发一次开窗，不必精确落进 3m 圈；1.4.10 起派兵只在**徒步**单位里挑人——选中的兵全在载具里时改派最近的徒步友军，1.4.10 同时修掉「让单位上坦克后又会立刻下车」与窗口标题和负重数字叠字）；右键地上物品 = 最近选中的士兵拾取。** 第一个打开的窗口为锚点，其余背包只能在锚点联动半径内打开/保持打开（cfg packRange，默认 3 米）。所有改动直接作用于士兵真实背包，AI 正常反应。**（1.4.11：点 ✕ 关窗、点菜单项都不再取消选中单位。）****右键格子 = 游戏原生交互菜单（1.4.0，1.4.1 起模态）：穿戴装备、吃食物、用医疗品、卸下——全部走游戏自己的交互管线执行（**1.4.12：穿戴为士兵补齐物品活体实例；原生调用若没生效则自动直写原生装备字段兜底——修掉"只能脱不能穿"**）。右键弹药箱等多交互地面物品会弹出它的原生菜单（补充弹药）；普通战利品联动半径内即时拾取，超半径由最近的选中士兵走去捡。**
- **载具与火力点**：点载具/火力点直接选中整车组（不用点里面的乘员）；右键友军/中立载具打开交互轮盘，逐员上车；通过轮盘下车/修理。
- **随机接管**：选中单位后点顶部 `[控制该小队]`，随机接管一名存活成员回到第一人称；全军覆没时可 F9 紧急退出。
- **RTS/FPS 共存**：切回 FPS 后，FPS 的 WASD、鼠标视角、射击和原生操作继续运行；已经下达的移动、集火、登车和车辆同步任务不会因退出 RTS 而被清除。接管某个单位时，只停止该单位自己的 Mod 持久任务。
- **原生指挥链**：移动/防守/登车全部走游戏自身命令入口（Squad.moveTo/HoldArea、boardVehicle），标记集火走原生目标选择（GetBestVisibleEnemy/CurrentVisibleTarget），Mod 不自建移动编排，只做下达与完成观测。
- **根治光标闪烁**：上帝视角下 patch `Cursor.set_lockState`，原生无法锁/隐藏光标——右键不再闪烁或重置到屏幕中央。
- **自定义光标**（`customCursor` / `cursorStyle`）：空心半透明圆环，颜色随指向对象变化（白=默认/绿=友军/红=敌军/青=载具/黄=建筑/橙=火力点/浅蓝=可交互）；`cursorStyle` = Circle（默认）/ Arrow / Cross。
- **压制原生干扰**：进入时解除本阵营小队的原生任务拉取；接管时自动关闭原生"选择队友"残留面板。

- Easy Red 2
- BepInEx（IL2CPP 版）

## 近期更新
**1.4.23**
· **距离修好后线又偏细了** —— 基准像素宽整体上调约 40%（步兵脚环 1.1 → 1.5、
  选中角标 1.6/1.9 → 2.2/2.6、集火环 2.2 → 3.0 …）。屏幕粗细仍与分辨率无关。
· **UI"完全就是棕色"的原因：半透明被地形染色。** α 0.82 时面板会透出棕色泥地，
  再怎么调色板也黑不下来。现在面板不透明度 0.92、底色压到近黑（#0C0906），只留极轻的暖调。
· **皮革质感。** 一个近黑矩形仍然只是"一块色板"，所以面板底改为三层：
  近黑填充 + 64×64 程序化皮革噪声纹理（两层倍频，确定性）以 10% 透明度平铺 + 顶部 1px 受光边。
  **是纹理和受光边读作"皮"**，不是颜色。
· **修掉面板最上面按钮的重叠。** 标题行原本高 26px，但内容从 +8 开始、按钮高 22px →
  Clear / × 两个按钮越过了标题条下的分隔线。现在标题行高 34px（8 + 22 + 4）。
· cfg 默认色同步压黑（#0F0B08 / #2A2017）。


**1.4.22**
· **线宽爆表的真因：相机距离取错了。** 标记线宽由相机距离推导，而这个距离原先用
  `cam.transform.position.magnitude`——那是相机到**世界原点**的距离，不是到标记的距离。
  ER2 地图原点离战区可达数百米，所以这个值永远是个错误的大数。旧版靠 `Clamp(0.6, 2.5)`
  倍率把它盖住；1.4.21 改成线性像素公式后，这个错值直接进了线宽——环被填成实心圆盘、
  选中角标糊成粗 X。现在改为"视线与地面交点的真实距离"（0.1s 缓存，GodView 与阵型标记共用一份）。
· **圆环不再用父对象缩放定尺寸。** 环原先仍用 `localScale = radius` 控制大小，而 LineRenderer
  线宽会被父级 `lossyScale` 连带放大——载具上环被放大到 4.2 倍。现在半径写进顶点
  （与角标同款修法），线宽是纯粹、可预测的世界值。
· **线条与圆点抗锯齿。** 线网格不吃 MSAA（截图锯齿明显）。现在线条沿宽度方向采样一张羽化纹理
  （两侧各 25% 平滑过渡），圆点用径向羽化圆盘，边缘从"台阶"变"干净"。圆环分段同时 48 → 64。
· **黑棕半透明 UI。** 配色由冷灰改为**暖黑棕 + 半透明**（面板 #1E1813@0.82、标题条 #2A2119@0.86、
  控件 #32271E@0.84、选中 #584331@0.96）。暖色在泥土/草地背景上协调得多，且面板能透出战场。
· **元素区分明显了。** 每个页签、阵营按钮、乘员按钮都加描边（未选中暖棕 / 选中暖白）；
  列表行之间加极细分隔线；面板描边与分隔线改暖棕——在黑棕底上才真正读得出边界。
· **文字不再与背景重叠。** 乘员 / 提示 / 标题 / 阵营 / 列表 / 分页这些行此前仍用硬编码像素，
  没有乘自适应倍率；而且行间距只内嵌在**部分**行里，导致乘员行与提示行紧贴在一起。
  现在这些尺寸全部随倍率，间距统一在行循环里加一次。
· 补全 16 条此前回退中文的英文 cfg 描述。


**1.4.21**
- **线宽改用「像素」定义**：`LineRenderer.widthMultiplier` 是世界单位，写死必然近粗远细；用「距离倍率」糊弄又会随分辨率跑偏（1440p 粗 1.33 倍、4K 粗 2 倍）。现在调用点只写 1080p 目标像素宽（1.1 最细 ~ 2.2 强调），由共享工具层按真实视距与相机 FOV 反算。任意视距、任意分辨率下屏幕粗细恒定。
- **选中角标不再是「箭头」**：真实成因是角标根对象被缩放到 `radius`，而 LineRenderer 线宽会被父级 `lossyScale` 连带放大——载具上 0.1m 的线被放大到约 0.5~1.0m，而折角臂长只有约 1m，两条粗臂糊成实心三角。现在根对象缩放恒为 1、半径写进顶点；臂长 0.34 → 0.42。
- **世界标记从半透明改为灰阶实色**：α 0.26~0.48 的半透明灰会被草地/雪地/沙地吃掉。现在全部改为近实色灰阶（α ≥ 0.80），层次靠灰度值（#9AA1A8 → #C6CBD0 → #E2E6EA → 纯白）。仅幽灵预览保留半透明。
- **面板补上结构而非纯色块**：新增 `Frame`（描边）、`HLine`（分隔线）、`AccentBar`（选中竖条）三个原语，加独立标题条底色、列表内凹边框、收藏行左竖条。层次从「只有面」变成「面 + 线 + 条」。
- **配色压回中深灰**（1.4.20 提亮过头）：面板 #14181D、标题条 #1F252C、控件 #262D35、悬停 #333B45、选中 #46505C。

**1.4.20**
