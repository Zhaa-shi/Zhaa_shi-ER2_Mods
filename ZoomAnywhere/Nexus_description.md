# ER2 Zoom Anywhere

## Description
Removes Easy Red 2's "stand still to hold breath" restriction. Hold your zoom key while moving, running, or in any stance. Optionally adds an extra zoom multiplier and supports hip-fire zoom.

## Installation instructions
1. Install BepInEx 6 (IL2CPP) for Easy Red 2.
2. Copy `ER2_ZoomAnywhere.dll` to `<Easy Red 2 folder>/BepInEx/plugins/`.
3. Launch the game. Default activation key is `Left Shift`.

## Main features
- Hold-breath zoom while moving / running / any stance.
- Optional hip-fire zoom (`withoutAiming = true`).
- Optional extra zoom multiplier (`extraZoom`, clamped 1.0–3.0).
- Configurable activation key (`holdKey`).
- Avoids stacking with magnified scopes.

## Requirements
- Easy Red 2
- BepInEx 6 (IL2CPP)
