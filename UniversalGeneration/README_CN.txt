ER2 Universal Generation v1.0.0
================================

在战场指挥官（ER2 Battlefield Commander）的 RTS 上帝视角内，按你的意愿生成任何单位与载具。
作弊向小工具：无平衡惩罚，全部走游戏原生管线，生成即可用。

需求（Requirements）
--------------------------------
- Easy Red 2（BepInEx IL2CPP）
- ER2 Battlefield Commander v1.0.1 或更新（本 mod 仅在其 RTS 上帝视角内工作，宿主缺失时保持休眠）

安装（Installation instructions）
--------------------------------
1. 解压，将 ER2_UniversalGeneration.dll 放入 <游戏>/BepInEx/plugins/
2. 确认 ER2_BattlefieldCommander.dll（v1.0.1+）已安装
3. 进入战斗，按 F9 进上帝视角，按 G（或点左下角"生成"按钮）

主要特性（Main features）
--------------------------------
- 三击出车：G → 点条目 → 点战场
- 全量条目：约 50 种官方小队类型（每场战斗自动探测）+ 游戏/DLC/内容 mod 全部载具（自动枚举）
- 阵营三选：我方 / 敌方 / 中立（平民）——生成后按阵营行为
- 载具自带正式乘员：按国别坦克组员、精确按座位数、完整原生登车流程（生成即可被 RTS 指挥）
- 乘员可自定义：专用坦克组员 / 任意步兵班型 / 空车
- 生成单位原地驻守、见敌接战——不会乱跑去占点，且完全听从你的指挥
- 收藏：条目一键加星，跨会话保存，收藏页集中显示
- 一键清除本 mod 生成的所有单位
- 双语（EN/CN），内置中文本地化

使用说明（How to use）
--------------------------------
- G：开关生成面板（RTS 视角内）
- 面板：选阵营 → 选类别 → 点条目 → 面板收起进入放置模式
- 放置：左键确认，Shift+左键连续放置，右键/ESC/G 取消
- 面板标题栏"清除"按钮：一键移除本 mod 生成的所有单位

已知限制
--------------------------------
- 单人模式验证；联机仅建议 host 使用
- 飞机地面生成后可能撞毁——小心使用
- 生成单位不保证跨阶段存活
