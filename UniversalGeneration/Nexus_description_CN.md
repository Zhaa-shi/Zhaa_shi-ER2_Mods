# Universal Generation（通用生成）

在战场指挥官的 RTS 上帝视角内，按你的意愿生成任何单位、载具与物品。基于游戏原生生成管线的沙盒/作弊工具——无平衡惩罚、无魔改单位，所有生成物与游戏自己生成的一模一样。

## Description（简介）

Universal Generation 在战场指挥官的 RTS 上帝视角内加入一个生成面板。选阵营、选条目、点战场——单位即刻落地，功能完整、可直接指挥。

- **步兵**：约 50 种基础小队 + 游戏小队库全部 400+ 战场/季节变体班（冬季、诺曼底、战争初期……），每场战斗自动探测，全员满配装备。
- **火力点**：游戏全部固定机枪——MG34、MG42、勃朗宁、马克沁、九二式、维克斯等，地面/三脚架/碉堡三种形态，另有高射机枪与 M45 四联装防空炮，默认自带机枪手。
- **载具**：游戏本体 + DLC 的全部坦克、卡车、飞机与火炮——运行时自动枚举，走游戏原生载具生成器。
- **物品** *（2.0.0 新增，2.0.2 重写目录）*：**直接向游戏运行时物品数据库枚举**，列表里出现的物品**一定能生成**。分 武器 / 弹药 / 投掷物 / 装备 / 医疗食物 / 其他 六类（分类取自游戏自己的物品类型），每条尽量显示**游戏真实图标**。点选即"拿起"，然后**拖到单位身上放进他的背包，或拖到地上丢出实物**。
- **阵营**：我方 / 敌方 / 中立（平民）。敌方会打你，中立按平民行为。
- **载具自带正式乘员且出生即在车上**：按国别的坦克组员、精确按座位数、原生 spawnOnvehicle 直接入座——生成的坦克即刻可被战场指挥官的 RTS 指令指挥。
- **我方驻守不乱跑**：生成单位原地驻守、见敌接战，永远服从你的 RTS 指令。**敌方走原生 AI**：自己推进进攻，与战役刷出的敌军无异（cfg 可改回驻守）。
- **收藏**：常用条目一键加星，跨会话保存。
- **一键清除**：随时移除本 mod 生成的所有单位。

独立 BepInEx 插件，仅在战场指挥官的 RTS 上帝视角内激活，其余场合完全休眠。

## Installation instructions（安装说明）

1. 安装 [BepInEx](https://bepinex.dev)（IL2CPP）与 **ER2 Battlefield Commander v1.2.19+**
2. 解压 `ER2_UniversalGeneration.dll` 到 `<游戏>/BepInEx/plugins/`
3. 进入战斗 → F9 进上帝视角 → 按 G

## Main features（主要特性）

- 三击出车：`G` → 点条目 → 点战场
- 面板零卡顿：目录在游戏启动时后台分帧构建
- 全量载具目录（本体+DLC），分类页签 + 收藏
- 约 50 种基础小队 + 小队库 400+ 战场/季节变体班
- 火力点专属页签：全部固定机枪，默认带机枪手
- **物品页签带真实图标**：拖到单位身上装满其背包，或拖到地上丢出实物
- 我方 / 敌方 / 中立阵营生成
- 我方驻守听指挥；敌方走原生 AI（cfg 可改驻守）
- 带乘员载具：国别坦克组员、精确座位数、原生可指挥
- 乘员自定义：专用坦克组员 / 任意步兵班型 / 空车
- Shift+左键 连续放置
- 一键清除全部生成物
- 中英双语界面

## How to use items（物品用法）

1. 打开面板（`G`），切到物品页签（武器 / 弹药 / 投掷物 / 装备 / 医疗食物 / 服装）
2. 点击一件物品——即"拿起"，光标处显示幽灵图标
3. 移到**单位身上**（绿色光环）松手 → 放进他的背包；移到**地面**（琥珀光环）松手 → 丢出实物
4. 右键 / `ESC` / `G` 放弃携带，不丢出任何东西

物品以**正确的子类**进背包——弹匣带正确弹药数、手雷按手雷行为、弹药按弹药堆叠。放入背包时会校验负重上限。

- 修复"物品页签一个都没有"。2.0.5 的看门狗**判断逻辑写反了**：它开头是"如果探测正在跑就什么都不做"，但协程被场景切换杀死时**没有任何代码会复位状态**（该复位的是已死的协程自己），于是状态永远停在"正在跑"，看门狗**永远以为一切正常、一次都不重启**，探测打印完"未就绪，逐帧轮询等待"就彻底沉默，物品页签建不出来。
- **判活改为"数协程的帧"，彻底不看时间**：协程每跑一帧计数器 +1，看门狗比对计数是否增长，**不增长即真死**并立即重启。与时间无关，场景加载/时钟漂移都骗不过它。此前几轮反复翻车的共同根源是"用时间流逝当协程死亡的判据"（2.0.3 用 150 秒、2.0.4 用 20 秒心跳），而**场景加载期间主线程被占住、协程停摆但时钟照走**，必然误判——该前提现已彻底去除。

**2.0.5**
- 修复"仍然没有物品选项"。2.0.4 逐帧轮询方向正确，但看门狗把**场景加载期间的正常停摆**误判为"协程已死"并重启；每次重启让计数 +1，**6 次触顶后"永久放弃"**——此后即使数据库早已就绪也不再重试。现已移除放弃路径，并加就绪诊断日志。

**2.0.4**
- 修复"物品生成仍然不可用"。2.0.3 的就绪判据修对了，但**每 2 秒才轮询一次**，等待窗口正好落在场景切换上被杀。现改为**每帧轮询**，就绪当帧即开始枚举；预算只在就绪后起算。

**2.0.3**
- 修复"物品生成整体不可用"。2.0.2 把物品目录改为向游戏运行时数据库枚举，但就绪判据只要求返回列表非 null——而数据库加载完成前，该方法返回的是**非 null 的空数组**。探测因此被瞬间放行、枚举到 0 条、随即标记为永久失败且再不重试，物品页签一个都建不出来，整个物品生成功能是死的。
  现在探测改为等待游戏自己的 `ItemsDatabase.Loaded` 标志**且**实枚举结果非空，未就绪重试（上限约 2 分钟），不再第一次就自杀；看门狗也不再误判"正常等待"。

**2.0.2**
- 修复"只有前面有图标的物品能生成，其他全部无法生成"：物品目录改为**直接向游戏运行时物品数据库枚举**。旧版从游戏磁盘上的预制品清单猜物品 id，但那份清单的文件名与运行时数据库的键并非同一套字符串——有些条目（ArisakaT38、Carcano、Syringe、Thompson_M1928 等）确实存在于磁盘却取不到；名称恰好一致的（bar_1918、bandages、ToolBox 等）才能生成。图标本身来自物品对象，于是"有没有图标"无意中成了"能不能生成"的标志。现在列表里只会出现确实能生成的物品，分类也改用游戏自己的物品类型。
- 移除全部服装条目：服装在游戏里不是可拾取物品而是换装数据，757 条全部无效。
- 物品目录改为启动时后台分帧枚举（每帧最多 3 毫秒），面板打开依旧零卡顿。

**2.0.1**

- 修复拖到单位身上经常失败（相机射线常先打中他身前的地面）：目标搜索半径改为按相机距离缩放；拖到地上时不再因为中间夹着一个士兵就拒绝。

## Known limitations（已知限制）

- 单人模式验证；联机仅建议 host 使用
- 物品图标是后台惰性解码的：刚打开物品页签滚动时，可能先显示名字、图标稍后出现
- 飞机地面生成后可能撞毁——小心使用
- 生成单位不保证跨阶段存活
- 任务编辑器创建的自定义小队无法生成：游戏运行时不暴露其成员数据
