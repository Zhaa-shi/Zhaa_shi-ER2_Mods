# 2026-09-24（第二轮）— v2.2.0 → v2.2.1：修字母行下标越界回归（用户第 14 轮「物品列表也不见了」）

## 现象（截图即诊断）
武器页签下：子分类页签（All/步枪/手枪/可穿戴）+ **孤零零一个「全部」按钮**，字母与整个物品列表全空。
—— 与 2.1.1 的 `GUI.TextField` 翻车同一模式：**"某段绘制之后全空白" = 那一段抛了异常**。

## 根因（我 2.2.0 修"按钮重叠"时引入）
「全部」改为占两格（i==0，宽 51px），但循环写 `else { letters[i - 2] }` ——
**i=1 时 `letters[-1]` 抛 ArgumentOutOfRangeException → 整帧 OnGUI 中断**。
教训：**改"按钮占位格"时必须把占位格与数据下标分开算**——`cells = count + 2` 时
i∈{0,1} 都属于「全部」的占位，数据下标只能从 i>=2 起取。修法 = `else` → `else if (i >= 2)`。

## ① 玩家报「上帝视角下打开设置后滚轮仍能控制视角」
