# ER2 Veteran HVT v1.2.2 — 老兵等级 · 高危标记 · 仇恨聚焦

## 简介
真正的战斗由少数精锐决定——而在本 mod 里，精锐会被**标记**。战场上每一次击杀都会被记录：一名单位杀得越多，它的**老兵等级**越高、也越致命。达到一级即被标记为**高危目标（HVT）**：被它屠杀的一方会把火力集中到它身上，干掉它则有明确的反馈。

## 安装说明
1. 需要 Easy Red 2 的 BepInEx 6（IL2CPP 版）。
2. 把 `ER2_VeteranHVT.dll` 放进 `Easy Red 2\BepInEx\plugins\`，并保留旁边的 `ER2_VeteranHVT` 文件夹（里面是击杀确认音效）。
3. 启动一次游戏，然后在游戏内 Mod Manager 页面配置（推荐），或编辑 `BepInEx\config\er2.highvaluetarget.cfg`。

## 主要功能
- **击杀归属与老兵等级：** 子弹、手雷/爆炸、近战甚至头盔爆头都会归属到具体士兵（命中在伤害结算前记录，瞬杀同样计入）。每 5 杀（默认）= 等级 +1，直到等级上限。战斗结束时等级重置（玩家死亡时也重置自身）。
- **防抢击杀：** 你在最近 5 秒内命中过的目标，即使最后一发是别人打的，击杀也算你的——混战中不再丢归属。
- **等级强化：** 每一级乘算受击伤害（×0.85）、造成伤害（×1.18）、命中率（×1.30）、射速（×1.15）、举枪速度（×1.15——游戏无独立举枪接口，并入射击间隔实现）与移速（×1.05）；1 级起无视压制、绝不投降，驾驶载具更快。5 级老兵是一支单人军队。
- **仇恨聚焦：** 被老兵屠杀过的一方会通过游戏自身的**目标选择**优先攻击它——聚焦半径内的敌方 AI 会把被标记单位当作最佳可见敌人，一边机动一边集火，掩体/换弹等原生行为不受影响（无强制锁定副作用）。
- **叛徒机制（可选）：** 玩家可以伤害友军（仅本 mod 穿透友军保护），击杀足够友军后己方会反过来攻击你、并主动追猎你。关闭该机制即完全失效：友军伤害不再计数，已有的叛徒标记会被清除。
- **标记（v1.2.2 — 真正的 3D + 真实透视）：** 深红（敌）/ 深蓝（友）菱形 + 白色罗马数字（I-V），以**世界空间广告牌**渲染、锚在单位上方——固定世界尺寸，靠近变大、远离变小，符合真实参照物直觉，并像普通 3D 物体一样被世界遮挡（被掩体挡住就看不见）。载具乘员合并为载具上方的**一枚**标记（显示乘员最高等级），载具武器击杀（坦克炮、同轴机枪）计入**全体乘员**，全车一起升级。
- **大地图集成：** 游戏没有常驻小地图——按 M。被标记单位会以彩色菱形出现在游戏自身单位标记旁边（载具乘员合并为一个图标），地图位置始终准确。
- **击杀反馈：** 消灭被标记单位会触发提示 + 金色闪烁 + 击杀确认音效；晋升与被标记都有明确提示（升级与被标记警告合并为单条消息）。
- **兼容 Hide Anything：** 与 "No Interaction Hints" mod 兼容——在其设置里勾选本 mod 的开关，即随其余 HUD 一起隐藏本 mod 的 UI。
- **可实时调参：** 每个数值都是 BepInEx 配置项，可在游戏内 Mod Manager 调整，无需重启。
- **单机优先：** 默认仅单机生效；可在设置里开启联机。
- **零冲突：** 只挂钩游戏自身的击杀/伤害/命中率/目标选择入口；不修改任何原版文件；删除 DLL 即完全卸载。不写入你的战役存档。

## 更新说明
### v1.2.2
- **标记缩放修复：** 标记改为固定世界尺寸（0.8 米），不再追求"屏上大小恒定"。屏上大小完全由真实透视决定——靠近变大、远离变小，像真实物体一样。此前的"恒定屏占比"方案实测在近处偏小、远处膨胀过度。
- 接入统一调试日志开关（`[Debug] debugLog`，默认关闭），可输出标记对账、击杀归属、叛徒判定等诊断日志。

### v1.2.1
- 新增跨 mod 公开接口 `ER2VeteranHVT.VeteranApi`：其他 mod 可读取/写入老兵等级与击杀数。这使战役类 mod 能实现**跨战斗持久化的老兵等级**——战役可在开战时把单位已保存的等级灌入新生成的士兵，并在战斗结束时读回击杀/等级。本身不改变玩法，除非有 mod 调用它。

### v1.2.0
- 头顶标记改为真正的 3D 世界空间广告牌：任何距离屏上大小恒定、始终清晰，并像普通 3D 物体一样被世界遮挡。
- 载具乘员合并为载具上方的**一枚**标记（显示乘员最高等级），不再每人一个。
- 载具武器击杀（坦克炮、同轴机枪）计入全体乘员，全车一起升级；M 大地图对载具只显示一个图标。
- 关闭叛徒机制后完全失效：友军伤害不再计数，已有的叛徒标记会被清除。
